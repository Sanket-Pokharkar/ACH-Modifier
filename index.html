Correction Rules
Batch Header positions 64-69: today in YYMMDD.
Batch Header positions 70-75: today + 2 days in YYMMDD.
Batch Control: Entry/Addenda Count, Entry Hash, Debit Total, Credit Total, and Batch Number.
File Control: Batch Count, Block Count, Entry/Addenda Count, Entry Hash, Debit Total, and Credit Total.
Entry Hash uses Type 6 Receiving DFI positions 4-11 and retains the rightmost 10 digits.
Existing padding is removed and exactly enough 94-character 9-records are added to complete a block of 10.
