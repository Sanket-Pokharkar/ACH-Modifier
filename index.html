Control Logic
File Control positions 2-7: number of Batch Header records.
File Control positions 8-13: total physical records divided by 10 after padding.
File Control positions 14-21: total Entry Detail and Addenda records.
Batch Entry Hash: sum positions 4-11 from each Type 6 record, keeping rightmost 10 digits.
File Entry Hash: sum all batch hashes, keeping rightmost 10 digits.
Type 22 is credit and Type 27 is debit. Other standard credit/debit codes are also supported.
Padding: Type 9 records containing 94 nines are added or removed until total lines are divisible by 10.
File Header positions 87-94 use DDHHMMSS.
